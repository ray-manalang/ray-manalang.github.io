What I'm building

Investment analysis platform

A three-layer stock analysis tool. A macro gate decides whether market conditions favor putting money to work at all, a factor scanner ranks the S&P 500, and an LLM analyst reviews the top candidates. If the model is unavailable, the app falls back to deterministic scoring instead of failing.

Content aggregator

Pulls news and video from many free sources into one personalized feed. Each scraper runs in its own container, so one broken source never takes the feed down.

Marketplace data app

Marketplace listings are messy: the same item shows up under a dozen different titles. This web app runs listings through an LLM pipeline that turns them into clean, consistent product records people can actually search.

Resume builder for students

A free resume-writing tool built on templates tailored to each industry and role. It runs completely stateless and collects no user data.
